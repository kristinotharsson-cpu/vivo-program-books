# Module Standardization Checklist

_Standard 9 modules enforced on every program book: Welcome · Today's Program · Program Notes · Song Texts · About the Artist · Vivo Supporters · Staff & Board · Next at Vivo · Audience Information._

For each book: **Cast & Creative** removed (still available in the module picker). Missing standard modules added as empty placeholders. Unique non-standard content (song notes, extra text, sponsors, rosters, promos, etc.) retained. `bios` title normalized to "About the Artist"; legacy `notes.blocks` normalized to `notes.sections`.

Reviewed **80** program books. Mirrored to _dist/shows for **80**.
